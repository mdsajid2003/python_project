## 🔍 Project Details

### 🪣 Water Jug Problem
A search-based solution to the classic AI problem: given two jugs of different capacities, measure an exact amount of water using BFS (Breadth-First Search) or DFS (Depth-First Search).

### 🧮 Calculator
An interactive command-line calculator that handles addition, subtraction, multiplication, and division with user input.

### 🎲 Prisoner's Dilemma
Simulates the one-shot Prisoner's Dilemma, a fundamental game theory scenario where two players must choose to cooperate or defect — illustrating why rational individuals may not cooperate even when it's in their best interest.

### 🤝 Tit-for-Tat Strategy
Extends the Prisoner's Dilemma into an **iterated** version and implements the famous Tit-for-Tat strategy — cooperate on the first move, then mirror the opponent's last move. Demonstrates how cooperation can emerge in repeated games.

### 🚪 Monty Hall Problem
Runs a Monte Carlo simulation of the Monty Hall Problem — proving through repeated trials that switching doors wins ~66% of the time, contrary to intuition.

### 🍀 Luck Simulation
A probability simulation that models luck/chance scenarios using Python's `random` module to observe outcomes over many trials.

### 🔤 String Operations
Covers essential Python string methods including slicing, concatenation, formatting, searching, replacing, and more.

### 📂 Working with Files
Demonstrates Python file I/O — creating, reading, writing, appending, and closing files using built-in functions like `open()`, `read()`, `write()`, and `with` statements.
